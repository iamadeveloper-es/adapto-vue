# Button

`adpt-button` is the standard clickable action element of Adapto UI. It supports five visual
variants, five sizes, a configurable corner radius, an optional icon (with an icon-only mode),
loading/disabled states, and a built-in ripple effect on interaction.

- **Component name:** `AdaptoButton`
- **Source:** `src/lib/components/adpt-button/index.vue`
- **Styles:** `src/lib/components/adpt-button/style.scss` (registered in `AdaptoPlugin`)

## Usage

Once [`AdaptoPlugin`](../../src/lib/plugin.ts) is installed on the app, `AdaptoButton` is
available globally:

```ts
// main.ts
import { createApp } from 'vue'
import { AdaptoPlugin } from 'adapto-ui'
import App from './App.vue'

createApp(App).use(AdaptoPlugin).mount('#app')
```

```vue-html
<AdaptoButton label="Save changes" @clicked="onSave" />
```

The visible text can also be provided through the default slot instead of the `label` prop —
`label` is always used as the accessible name (`aria-label`) regardless of which one is used:

```vue-html
<AdaptoButton label="Save changes">Save changes</AdaptoButton>
```

## Variants

The `variant` prop controls the visual style. Default is `soft`.

<div class="demo">
  <AdaptoButton variant="outlined" color="primary-500" label="Outlined" />
  <AdaptoButton variant="fussy" color="primary-500" label="Fussy" />
  <AdaptoButton variant="soft" color="primary-500" label="Soft" />
  <AdaptoButton variant="soul" color="primary-500" label="Soul" />
  <AdaptoButton variant="link" color="primary-500" label="Link" />
</div>

```vue-html
<AdaptoButton variant="outlined" color="primary-500" label="Outlined" />
<AdaptoButton variant="fussy" color="primary-500" label="Fussy" />
<AdaptoButton variant="soft" color="primary-500" label="Soft" />
<AdaptoButton variant="soul" color="primary-500" label="Soul" />
<AdaptoButton variant="link" color="primary-500" label="Link" />
```

| Variant    | Description                                                                             |
| ---------- | ---------------------------------------------------------------------------------------- |
| `outlined` | Transparent background with a `currentColor` border.                                    |
| `fussy`    | Border **and** a tinted (`color-mix`) background — the most visually prominent variant.  |
| `soft`     | Tinted background, no border. **Default.**                                              |
| `soul`     | Fully transparent background, no border — text/icon only until hover.                    |
| `link`     | Transparent background styled like a hyperlink; hover/focus reduce opacity instead of showing the ripple highlight. |

Every variant (except `link`) gets a `currentColor`-based hover/focus highlight, and derives its
background from the button's resolved text color via `color-mix`.

## Colors

The `color` prop accepts the name of a theme token (primitive, e.g. `green-500`, or semantic,
e.g. `primary-500`, `danger-700`) as it is exposed on the CSS custom properties generated by the
theme, i.e. `--adapto-<color>`. It sets the button's text color (`currentColor`), which the
variants above then reuse for borders and tinted backgrounds.

<div class="demo">
  <AdaptoButton variant="fussy" color="primary-500" label="Primary" />
  <AdaptoButton variant="fussy" color="secondary-500" label="Secondary" />
  <AdaptoButton variant="fussy" color="success-600" label="Success" />
  <AdaptoButton variant="fussy" color="warning-600" label="Warning" />
  <AdaptoButton variant="fussy" color="danger-600" label="Danger" />
</div>

```vue-html
<AdaptoButton variant="fussy" color="primary-500" label="Primary" />
<AdaptoButton variant="fussy" color="secondary-500" label="Secondary" />
<AdaptoButton variant="fussy" color="success-600" label="Success" />
<AdaptoButton variant="fussy" color="warning-600" label="Warning" />
<AdaptoButton variant="fussy" color="danger-600" label="Danger" />
```

::: warning No color provided
If `color` is left empty (the default), the button currently falls back to the literal CSS
color `red`. Always pass an explicit token to get an intentional result.
:::

## Icons

Pass an `icon` object (`{ name, size?, color?, strokeWidth?, defaultClass? }`, matching the
`Icon` type and forwarded to `AdaptoIcon`/lucide) to render an icon alongside the label. If
`size` is omitted, it is derived from the button's computed font size.

<div class="demo">
  <AdaptoButton color="primary-500" label="Download" :icon="{ name: 'download' }" />
  <AdaptoButton color="primary-500" label="Next" :icon="{ name: 'arrow-right' }" icon-prepend />
</div>

```vue-html
<!-- icon rendered before the label (default) -->
<AdaptoButton color="primary-500" label="Download" :icon="{ name: 'download' }" />

<!-- iconPrepend reverses the layout, moving the icon after the label -->
<AdaptoButton color="primary-500" label="Next" :icon="{ name: 'arrow-right' }" icon-prepend />
```

### Icon-only button

Combine `icon` with `hideLabel` to render an icon-only button. `label` is still required in this
case — it becomes the accessible name via `aria-label`, and the icon is marked `aria-hidden`.

<div class="demo">
  <AdaptoButton variant="soul" color="primary-500" label="Settings" :icon="{ name: 'settings' }" hide-label />
</div>

```vue-html
<AdaptoButton
  variant="soul"
  color="primary-500"
  label="Settings"
  :icon="{ name: 'settings' }"
  hide-label
/>
```

## States

<div class="demo">
  <AdaptoButton color="primary-500" label="Disabled" disabled />
  <AdaptoButton color="primary-500" label="Loading" loading />
  <AdaptoButton color="primary-500" label="No ripple" disable-ripple />
</div>

```vue-html
<AdaptoButton color="primary-500" label="Disabled" disabled />
<AdaptoButton color="primary-500" label="Loading" loading />
<AdaptoButton color="primary-500" label="No ripple" disable-ripple />
```

- **`disabled`** — sets the native `disabled` attribute and blocks the `clicked` emit.
- **`loading`** — shows an inline spinner, sets `aria-busy="true"`, and blocks the `clicked`
  emit (without disabling the button visually or setting `disabled`).
- **`disableRipple`** — turns off the `v-ripple` click feedback while keeping the button
  otherwise interactive.

## Props

| Prop            | Type                                                              | Default    | Description                                                                 |
| ---------------- | ------------------------------------------------------------------ | ---------- | ----------------------------------------------------------------------------- |
| `variant`         | `'outlined' \| 'fussy' \| 'soft' \| 'soul' \| 'link'`               | `'soft'`   | Visual style of the button.                                                  |
| `color`           | `string`                                                            | `''`       | Theme token name (e.g. `primary-500`) resolved to `var(--adapto-<color>)` and used as the button's text color. |
| `size`            | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`                              | `'xs'`     | Controls padding and font size.                                              |
| `radius`          | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl' \| 'full'`                    | `'sm'`     | Corner radius, via the shared `.rounded--*` utility classes.                 |
| `type`            | `'button' \| 'submit' \| 'reset'`                                   | `'button'` | Native `type` attribute of the `<button>` element.                          |
| `disabled`        | `boolean`                                                           | `false`    | Disables the button and blocks the `clicked` emit.                          |
| `loading`         | `boolean`                                                           | `false`    | Shows a spinner, sets `aria-busy`, and blocks the `clicked` emit.            |
| `fullWidth`       | `boolean`                                                           | `false`    | Stretches the button to `width: 100%`.                                      |
| `label`           | `string`                                                            | `'Botón'`  | Visible text (unless overridden by the default slot) and always the `aria-label`. |
| `hideLabel`       | `boolean`                                                           | `false`    | Hides the visible label span, producing an icon-only button.                |
| `icon`            | `Icon` (`{ name, size?, color?, strokeWidth?, defaultClass? }`)     | `undefined`| Icon rendered via `AdaptoIcon`. Omit to render no icon.                     |
| `iconPrepend`     | `boolean`                                                           | `false`    | Reverses the flex order of icon/label — `false` renders the icon first.     |
| `disableRipple`   | `boolean`                                                           | `false`    | Disables the `v-ripple` click feedback.                                     |

## Emits

| Event     | Payload      | Description                                                        |
| --------- | ------------ | -------------------------------------------------------------------- |
| `clicked` | `MouseEvent` | Emitted on click, unless the button is `disabled` or `loading`.     |

## Slots

| Slot      | Description                                                                 |
| --------- | ------------------------------------------------------------------------------ |
| `default` | Overrides the visible label content. Falls back to the `label` prop text. Only rendered when `hideLabel` is `false`. |

## Accessibility

- The button always exposes `label` as its `aria-label`, independently of whether the visible
  text comes from the `label` prop or the default slot, and even when the label is visually
  hidden (`hideLabel`).
- `loading` sets `aria-busy="true"` on the button while the request is in flight.
- When `hideLabel` is used together with `icon`, the icon is marked `aria-hidden="true"` so
  assistive technology relies solely on `aria-label`.
- Focus and hover states are visible by default (`currentColor`-based highlight) for all variants
  except `link`, which uses an opacity change instead.
